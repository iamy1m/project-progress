# 预约取消：需求

本文件是虚构教学设定，不代表真实用户需求或生产规则。

关联：[项目入口](../process.md) · [方案](../designs/预约取消.md)

## 目标与范围

增加预约取消入口。本例不处理退款，不改变其他预约状态流转。

## 已确认规则：教学设定

- 仅尚未开始的预约允许取消。
- 已取消的预约重复请求返回已取消，不重复执行取消操作。
- 已经开始的预约不允许取消。

范围依据为已归档的教学报告，路径以项目资料根目录为基准：`agent/archive/预约取消-scope-范围确认.md`。

## 验收条件

- 符合条件的预约可以取消。
- 对应测试资料分别记录预期与实际结果。

## 待确认

接口方式、返回字段以及 UI 交互仍待确认。协作方报告中的方案建议不自动成为已批准的需求。
